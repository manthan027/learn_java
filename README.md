"# learn_java

This repository contains a collection of Java learning examples, Playwright automation samples, and small practice projects.

## Contents

- Java and web development practice files under the learn_java-main folder
- Playwright test examples in the tests folder
- Sample UI pages and demo projects for hands-on learning

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the Playwright tests:
   ```bash
   npx playwright test
   ```
3. Open the HTML demo pages locally from the learn_java-main folder

## Project Structure

- learn_java-main/: Java, HTML, CSS, and JavaScript practice files
- tests/: Playwright test specifications
- playwright.config.ts: Playwright configuration

## Notes

This project is intended for learning, practice, and experimentation with web automation and front-end development.
